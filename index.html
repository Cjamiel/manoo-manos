Install Manoo

The easiest way: the installer checks your computer, installs what's missing, walks you through the permissions and installs Manoo in Claude Code. Paste one line in a terminal, then point Claude Code at DeepSeek (step 2 below):

macOS (Terminal)

curl -fsSL /instalar.sh | bash

macOS (Terminal)

1. The Manoo app (no Claude Code needed): the finished app for DeepSeek — its own window, the on-screen bar, the teaching ring and the voice.

Download Manoo for DeepSeek (macOS)

Or use it inside DeepSeek Harness: install the connector from the plugin market (search «Manoo») and Manoo’s tools show up in the chat. Or run:

dsh plugin --profile web add manoo-manos

Prefer to do it by hand?

Also possible: inside Claude Code

You need Claude Code and Node.js. Run these two commands, then restart Claude Code:

claude plugin marketplace add https://manoo.corporacionjamiel.workers.dev/marketplace.json
claude plugin install manoo@manoo-local

2. Point Claude Code at DeepSeek

Get a key at platform.deepseek.com, then export these variables in the terminal before running Claude Code. They last only for that terminal:

export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN=<your DeepSeek API key>
export ANTHROPIC_MODEL=deepseek-flash[1m]
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-flash[1m]
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-flash

Careful: this way it is Claude Code that talks to DeepSeek. If you do not use Claude Code, install the Manoo app (below): it talks to DeepSeek directly and needs no Claude at all.

Prefer the Claude desktop app? Point it at the DeepSeek API in developer mode and install the same Manoo extension. Download Manoo for Claude desktop
