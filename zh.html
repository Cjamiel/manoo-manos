安装（三种方式）

1 · 装 Manoo 应用（不用装 Node）

一行命令，它会自己检查、自己下载所需的一切（包括 Node，装在 Manoo 里面，不动你的系统）。

curl -fsSL https://manoo-deepseek.corporacionjamiel.workers.dev/instalar.sh | bash

需要 macOS，以及三个系统权限：辅助功能、屏幕录制、输入监控（最后一个就是紧急停止）。

想让 Manoo 的中文听起来更自然：系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音， 下载一个带「增强」或「高级」的中文（普通话）声音。装好之后 Manoo 会自动用它，不用设置。

2 · 用在 DeepSeek Harness 里

在插件市场搜「Manoo」安装，或者：

dsh plugin --profile web add manoo-manos

3 · 用在 Claude Code 里（可选）

如果你已经在用 Claude Code，把它指向 DeepSeek 的 API 就行。这一条不是必需的。

它不会做的事（写在代码里）

  • 绝不输入密码、PIN、卡号或验证码。
  • 绝不按最后一个按钮：付款、转账、签名、发布——它指给你，你自己按。
  • 不进银行、投资、加密货币、密码管理器和税务应用。
  • 你一碰鼠标或键盘，它立刻停下，并问你要不要继续。
  • 第一次碰到某个应用时会先问你，圆环指在「允许」上。
